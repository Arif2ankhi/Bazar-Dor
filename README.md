# 🛒 বাজার দর (বাজারদর / BazarDor)

**বাজার দর** is a modern, responsive daily market price tracking and management web application designed for consumers to check, sort, and track essential commodity prices across different local markets in real-time.

## 🚀 Live Demo & Repository
# Live URL:** https://bazar-dor-black.vercel.app/

---

## 📌✨📌 Key Features

* **Dynamic Marquee with live price changes and trends:** Features an infinite scrolling price ticker right below the navbar displaying real-time commodity fluctuations and percentage changes.
* **Responsive Grid layout for 80+ daily products:** Displays comprehensive daily essentials in a clean, fully responsive grid layout optimized for mobile, tablet, and desktop screens.
* **Multi-criteria Sorting with native Bengali numeral support:** Advanced sorting controls allowing users to seamlessly organize items by default, price (Low to High), and price (High to Low) handling Bengali numerals correctly.
* **🔒 BetterAuth Security (Proxy Protected & OAuth):** Secure authentication architecture leveraging BetterAuth with Email/Password, Google/GitHub social logins, and proxy-protected routes (such as product details and user profiles).
* **Protected User Profile with Update capabilities:** Dedicated user dashboard and profile management route complete with secure update functionality to modify user account details.

## 🛠️ Technologies Used

* **Frontend & Framework:** [Next.js (App Router)](https://nextjs.org/) (React)
* **Styling & UI:** [Tailwind CSS](https://tailwindcss.com/), [DaisyUI](https://daisyui.com/), [React Icons](https://react-icons.github.io/react-icons/), and `react-marquee-text`
* **Authentication & Proxy:** [BetterAuth](https://www.better-auth.com/) with `@better-auth/mongo-adapter`
* **Database:** [MongoDB](https://www.mongodb.com/)
* **Notifications:** `react-hot-toast`
* **Language:** JavaScript
